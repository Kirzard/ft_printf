ft_printf
Description

ft_printf is a 42 School project that consists of recreating the behavior of the standard C library function printf().

The goal is to understand variadic functions in C, manage different data types, and implement formatted output.

The project reproduces the main functionalities of the original printf() function using the write() system call.

It also relies on my own libft library, developed previously during the 42 curriculum.

Supported conversions
Specifier	Description
%c	Prints a single character
%s	Prints a string
%p	Prints a pointer address in hexadecimal
%d	Prints a decimal integer
%i	Prints an integer
%u	Prints an unsigned decimal integer
%x	Prints a number in lowercase hexadecimal
%X	Prints a number in uppercase hexadecimal
%%	Prints a percent sign

File Organization
ft_printf.c: Main function responsible for parsing the format string and handling variadic arguments.
ft_printf.h: Header file containing function prototypes and required includes.
ft_putnbr_count.c: Handles the printing of signed integers and counts printed characters.
ft_putnbr_hex.c: Handles hexadecimal number conversions.
ft_putstr_count.c: Handles string output and character counting.
ft_putunsnbr_count.c: Handles unsigned integer output and character counting.
put_adr_hex.c: Handles pointer address conversion and hexadecimal output.
which_flag.c: Identifies and dispatches the appropriate conversion specifier.
libft/: Contains my own library of reusable C functions.
Makefile: Automates the compilation of the project and its dependencies.

Usage

To use ft_printf() in a C program, include the header file.

Example:

c
#include "ft_printf.h"

int main(void)
{
    ft_printf("Hello %s! Number: %d\n", "42", 42);
    return (0);
}


Compile and link your program using the library generated by the Makefile.

bash
cc main.c -L. -lftprintf -Llibft -lft -I. -Ilibft -o program


Run the program:

bash
./program


Note: The linking command assumes that the Makefile generates libftprintf.a and that libft generates libft.a inside the libft/ directory.

Algorithm and Data Structure
Algorithm

The implementation uses a sequential parsing algorithm to process the format string.

The algorithm follows these steps:

Initialize a va_list using va_start() to access variadic arguments.
Iterate through the format string character by character.
If the current character is not %, print it directly.
If a % is encountered, inspect the following character to identify the conversion specifier.
Call which_flag() to identify the appropriate conversion.
Retrieve the corresponding argument using va_arg().
Call the dedicated conversion function to format and print the value.
Keep track of the number of characters printed.
Continue until the end of the format string.
Call va_end() and return the total number of characters printed.
Data Structures

The main data type used is va_list, provided by <stdarg.h>.

It allows the function to handle a variable number of arguments.

The following macros are used:

va_start(): Initializes the argument list.
va_arg(): Retrieves the next argument with the expected type.
va_end(): Ends the argument list.

No complex data structures are required because the format string is processed sequentially.

Technical Choices

The project is divided into specialized functions, each responsible for a specific conversion or operation.

This modular approach provides:

Better code organization.
Easier debugging and maintenance.
Reusability of conversion functions.
Separation of parsing and printing responsibilities.

The write() system call is used to output characters directly to the standard output.
